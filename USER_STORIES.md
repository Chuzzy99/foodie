# Foodie App - Capstone User Stories

Below are the 9 core user stories defining the requirements, behaviors, and benefits of the Foodie React Native mobile application.

---

### User Story 1: User Registration (Signup)
**As a** new culinary enthusiast,  
**I want to** register for an account using my username, email address, and a secure password with real-time validation,  
**so that** I can create a personal profile to manage my cooking journey and securely store my recipes.

---

### User Story 2: User Authentication (Login & Session)
**As a** registered Foodie user,  
**I want to** log in with my verified email and password and have my active session remembered across app restarts,  
**so that** I can quickly access my saved recipes without repeatedly typing my credentials.

---

### User Story 3: Recipe Discovery & Category Browsing
**As a** home cook,  
**I want to** browse recipes categorized with an interactive horizontal scroll bar (including All, Breakfast, Lunch, Dinner, Dessert, Salad, Soup, Pasta, Seafood, Vegetarian, Snacks, Drinks, and My Food),  
**so that** I can effortlessly filter and find meal inspiration that matches my dietary craving or meal type.

---

### User Story 4: Detailed Recipe View
**As a** home chef preparing a meal,  
**I want to** tap any recipe card to open a full recipe detail screen displaying the prep time, servings, calories, difficulty level, structured ingredients checklist, and numbered step-by-step cooking instructions,  
**so that** I can follow clear, accurate guidance to cook the dish successfully.

---

### User Story 5: Favorites & Bookmarking
**As a** regular user,  
**I want to** toggle a heart icon on any recipe card or detail page to save it to my dedicated Favorites screen,  
**so that** I can immediately retrieve and prepare my most cherished meals anytime.

---

### User Story 6: Custom Recipe Management (Add, Edit, Delete)
**As a** creative cook with family recipes,  
**I want to** add new recipes with custom photos, edit existing ones, or delete outdated recipes under the "My Food" section,  
**so that** my personalized recipe collection remains up to date and tailored to my kitchen.

---

### User Story 7: Offline Local Storage Persistence
**As an** on-the-go user cooking with intermittent connectivity,  
**I want to** have my accounts, active session, favorites, custom recipes, and app settings persisted locally in AsyncStorage,  
**so that** I never lose my recipe collection and can inspect stored data via the Stored Data Inspector screen.

---

### User Story 8: Third-Party Recipe Integration (TheMealDB API)
**As a** curious cook seeking new culinary ideas,  
**I want to** explore live online recipes fetched from TheMealDB API with real-time loading feedback, error recovery, and offline caching,  
**so that** I can discover international dishes beyond the preloaded catalog.

---

### User Story 9: Settings, Preferences & Cooking Notifications
**As a** busy foodie,  
**I want to** customize my app preferences with a dark mode toggle, configure cooking reminders, and test local alerts via expo-notifications,  
**so that** the app is comfortable to use in any lighting and reminds me when it is time to cook something delicious.
